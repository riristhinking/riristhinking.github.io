Privacy Policy

Effective date: July 27, 2026 · Last updated: July 27, 2026

This Privacy Policy explains how Riri (the "Application") handles data. Riri is a personal automation tool operated by a single individual (the "operator") to publish the operator's own original illustration videos to the operator's own social media accounts, including the operator's TikTok account @riristhinking, via each platform's official API.

1. No End Users

The Application has no public users, no sign-up, and no user accounts. The only person who uses the Application is the operator who installs and runs it. The Application does not collect, request, or process personal information from any member of the public.

2. Information the Application Uses

To function, the Application stores and uses the following entirely on the operator's own infrastructure:

  • Authorization tokens — OAuth access and refresh tokens issued by TikTok, YouTube, and Instagram/Meta when the operator authorizes the Application on the operator's own accounts. These tokens are used solely to publish the operator's own videos and are stored only on the operator's own infrastructure. They are never shared with any third party.
  • Account identifiers — Basic identifiers returned by each platform (for example, the account identifier needed to post) are used only to complete a publish request. They are not used for profiling or advertising.
  • Notion API credentials — A private token used to read the operator's own publishing queue from the operator's own Notion workspace.

The Application does not collect names, email addresses, contacts, location, device identifiers, browsing history, or any personal data belonging to other people.

3. How TikTok Data Is Used

When the operator authorizes the Application with TikTok, the Application requests only the scopes needed to upload and publish video to the operator's own TikTok account (content posting). Data received from TikTok is used only to carry out that publishing action requested by the operator. The Application does not sell, rent, share, or transfer any TikTok data to third parties, and does not use it for advertising or analytics.

4. Data Sharing

The Application shares data only with the third-party platforms strictly necessary to perform the operator's requested action: TikTok, YouTube, and Instagram/Meta (to publish the operator's own videos to the operator's own accounts) and Notion (to read the operator's own publishing queue). No data is shared with advertisers, data brokers, or any other third party.

5. Data Retention and Deletion

Authorization tokens are kept only as long as needed to operate the Application and can be deleted by the operator at any time. The operator can also revoke the Application's access directly through each platform's authorized-apps settings (for TikTok: Settings → Security → Manage app permissions). Revoking access immediately invalidates the stored tokens.

6. Security

Credentials and tokens are stored privately on the operator's own infrastructure, are not committed to source control, and are not exposed publicly. Because the Application runs privately for a single operator, there is no shared server storing third-party personal data.

7. Children's Privacy

The Application is not directed to children and does not knowingly collect any information from anyone, including children under 13.

8. Changes to This Policy

This Privacy Policy may be updated from time to time. The "Last updated" date above reflects the most recent revision.
